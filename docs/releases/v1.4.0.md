## ✨ 새 기능

### v1.4.0
- **사용자별 하루 다운로드 횟수**: 관리자가 계정 탭에서 사용자마다 "기본 설정 따르기 · 하루 N회 · 무제한"을 지정할 수 있습니다. 새 사용자를 추가할 때도 바로 지정할 수 있습니다.

### v1.3.0
- **도서 목록 페이지네이션**: 한 페이지에 12권씩 표시합니다.
- **표지 우선 디자인**: 드래그 손잡이 · 형식 · 인기 배지를 반투명으로 바꿔 표지를 가리지 않습니다.

### v1.2.0
- **관리자 도서 표 페이지네이션**: 페이지당 10 · 20 · 50권 또는 전체를 고를 수 있습니다.

### v1.1.0
- **회원 책 등록**: 마이페이지 → 내 책에서 직접 등록하고, 본인 책만 수정 · 삭제할 수 있습니다.
- **책 상세 정보**: 카드를 누르면 표지 · 소개 · 다운로드 횟수 · 등록자를 보여 줍니다.
- **인기 도서 TOP 3**: 옅은 파랑 테두리와 🏆 순위 배지로 표시하고, "인기순" 정렬을 추가했습니다.
- **다운로드 횟수 표시**와 **책별 다운로드 기록(관리자)**을 추가했습니다.

## 🔧 업그레이드 방법

기존 `data/` 폴더를 그대로 두고 코드만 교체하면 됩니다. 데이터 형식은 이전 버전과 호환됩니다.

```bash
git pull origin main
```

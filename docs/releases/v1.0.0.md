## 🎉 Share Park 첫 릴리스

개인이 소유한 PDF/EPUB 전자책을 등록하고, 로그인한 사용자가 **개인용도 동의서**에 동의한 뒤 다운로드할 수 있는 셀프 호스팅 전자책 라이브러리입니다.
데이터베이스 없이 **순수 PHP + JSON 파일**만으로 동작합니다.

> 이 버전은 첫 공개 버전입니다. 최신 기능은 [최신 릴리스](https://github.com/resious71/Share_Park/releases/latest)를 확인해 주세요.

## ✨ 주요 기능

### 📖 사용자
- ID/PW 로그인 (PHP 세션 + bcrypt), 관리자 · 일반 사용자 권한
- 타일형 도서 목록, 제목 · 저자 검색, 정렬(커스텀 · 제목 · 저자 · 추가일)
- 드래그 앤 드롭으로 나만의 책 순서 저장 (마우스 · 터치 · 키보드)
- 하루 다운로드 제한과 "오늘 N회 남음" 배너
- 마이페이지: 프로필, 비밀번호 변경, 다운로드 히스토리(검색 · 페이지)

### 📜 개인용도 동의서
- 다운로드 전 동의서 모달, 체크해야만 다운로드 버튼 활성화
- 서버 검증 후 발급하는 1회용 다운로드 토큰 (5분 유효)
- 모든 동의 기록 보관 (사용자 · 책 · 시각 · IP · 동의서 버전), "7일 동안 다시 보지 않기"

### 🛠️ 관리자
- 계정 관리 (추가 · 비밀번호 변경 · 삭제 · 다운로드 제한 초기화 · 히스토리 조회)
- 도서 관리 (드래그 앤 드롭 업로드 · 진행률 · 수정 · 삭제 · 표시 순서)
- PDF/EPUB 표지 하이브리드 자동 추출
- 설정 (사이트 제목 · 하루 다운로드 제한 · 초기화 시각 · 파일 크기 · 저장 경로 · 동의서 문구)
- 다운로드 통계 (오늘 · 이번 달 · 누적), 최근 다운로드, 인기 도서, 동의 기록
- 가이드 · FAQ · 도움말 팝업 · 첫 방문 둘러보기

## 🚀 설치

```bash
git clone https://github.com/resious71/Share_Park.git
cd Share_Park
git checkout v1.0.0
php -S localhost:8000 -d upload_max_filesize=64M -d post_max_size=70M
```

http://localhost:8000 에 접속해 `admin` / `admin` 으로 로그인한 뒤 비밀번호를 바로 변경하세요.

## 📦 요구 사항

PHP 8.1 이상 (json, mbstring, fileinfo, session / 권장: zip, gd)
